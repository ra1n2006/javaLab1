# Сервис для работы с матрицами комлпексных чисел

## Работа с консольным интерфейсом:

### Сначала нужно задать матрицу (матрицы), которая сохранится в список текущих матриц, а также дать ей имя. Всё это будет описано в интефейсе. 
### Вводить элементы матрицы следует через пробел, комплексные числа вводятся в формате a+bi, **без пробелов между слагаемыми самого числа**


### Затем можно применять команды из доступных (они будут выведены в консольный интерфейс)

- сначала надо написать название команды, которую надо выполнить
- затем написать название матрицы (или матриц), с которыми выполняется команда

## Важно

### алгоритм расчета определителя строится на вычислении миноров, сложность этого алгоритма - O(n!), поэтому для квадратных матриц больше 12х12 вычисление определителя займет больше 5 минут.
### то же самое и для деления матриц
